# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's
[private vulnerability reporting](https://github.com/jsundquist/knowledgebase/security/advisories/new)
(Security tab → Report a vulnerability). Don't open a public issue for a security problem.

This is a solo-maintained project, so response is best effort: expect an acknowledgement within
7 days and a fix or status update within 30 days.

## Supported versions

Only the latest `main` is supported. There are no tagged releases.
